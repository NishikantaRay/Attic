# Social cards

Generated by `node scripts/make-social-set.js`, then rasterised:

```sh
node scripts/make-social-set.js
cd assets/social
for f in compounding correctness-tie problem; do rsvg-convert -w 2400 -h 1254 $f.svg -o $f.png; done
rsvg-convert -w 2160 -h 2160 square.svg -o square.png
```

Every figure is read from `benchmarks/results/`, so a card cannot outlive the
run behind it. Nothing is hand-typed.

| Card | Size | Use it for |
|---|---|---|
| `compounding.png` | 2400×1254 | The strongest claim: the benefit grows per session |
| `correctness-tie.png` | 2400×1254 | Credibility: same correctness, a third fewer tokens |
| `problem.png` | 2400×1254 | Feeds where a percentage starts a methodology argument |
| `square.png` | 2160×2160 | Instagram, LinkedIn carousels |

Sizes are 2× for retina. All fit LinkedIn's 1.91:1 and X's 16:9 crops.

## Copy to pair with each

### `compounding.png` — X / Twitter

> Your coding agent figures something out. Then `/compact` runs and it's gone.
> Tomorrow it reads the same ten files again.
>
> I benchmarked a fix across three sessions on a real repo:
>
> Session 1: −6%
> Session 2: −36%
> Session 3: −43%
>
> Session one pays. Later sessions collect.

### `correctness-tie.png` — X / Twitter, or LinkedIn

> Both arms scored 13/13 on a graded rubric.
>
> So this doesn't make your agent smarter. It stops it paying twice for the
> same discovery. Worth being precise about which one you're selling.

### `problem.png` — LinkedIn

> **Your AI coding agent forgets what it just figured out.**
>
> It reads ten files, traces the flow, finds the cause. Then the context
> fills up, compaction runs, and that understanding is gone. Tomorrow it
> reads the same ten files.
>
> Attic writes those findings to a `.attic/` folder instead, keeping one line
> in the conversation.
>
> Three sessions on a real codebase, with sessions 2 and 3 told nothing about
> session 1: input tokens fell 34%, and correctness tied at 13/13.
>
> Where it costs you: short sessions, questions you never ask twice. That's
> measured too, and it's why the plugin ships an off switch.
>
> Open source, MIT, no telemetry.

### `square.png` — Instagram, carousels

> Your agent forgets what it figured out. Attic writes it down.
>
> Measured across three sessions: −6%, −36%, −43% input tokens. Same
> correctness.
>
> Link in bio.

## What not to claim

**Don't lead with 34%.** One run, one repo, one model. It invites a
methodology argument you lose on sample size. The compounding shape and the
correctness tie are more defensible and more interesting.

**Don't imply better output.** The benchmark says the opposite and someone
will check.

**Do mention the off switch.** Naming where it costs you buys more
credibility than any percentage.
